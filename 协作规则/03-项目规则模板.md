# 项目规则模板

> 正式模板：2026-09-27（修订）。用于生成项目根 AGENTS.md。何时建档、由谁建、做到什么算完成，见 [02 新项目启动与最少建档](02-通用开发规程.md#project-startup)。

## 使用前

- `[方括号]` 是待核实的占位符，不是事实、路径或命令。
- 逐项核实；不适用写“不适用＋理由”，未确认写“待确认”。
- 路径指向真实文件。已有合适的目录和文件沿用，不为套模板搬迁。
- 根 AGENTS.md 是唯一项目规则正文。CLAUDE.md 如需接入，作为工具入口引用它，接法见 [06](06-规则维护与启用检查.md)。
- 体量：01 加项目 AGENTS 合计保持在 32 KiB 以内，数字和原因见 06 的接入说明；量法和清理线见 02 第 6 节。
- 全文只写现行事实，不写日期、提交号、经过和原话；变化经过在票、决策卡、Spec 变更记录和 Git 历史，需要时去原处看。

## 项目资料目录

新项目按下表建立；目录随实际内容建立，不预建空目录。已有项目沿用现有位置，在下一节登记真实路径。

| 位置 | 内容 | 写手 |
|---|---|---|
| `AGENTS.md` | 唯一项目规则正文，含下方路由 | 主控 |
| `README.md` | 项目介绍和人类阅读入口，不维护进度 | 主控 |
| `项目总览/md/施工日志.md` | 项目当前状态的唯一事实源，六项：当前阶段、决策现场、当前票、上一票验收结果、待用户决定的事、下一步 | 主控 |
| `项目总览/md/决策地图.md` | 决策台账总表：开头是头字段，之后每个问题一行索引；写法见共享规程 03“决策卡写法”末尾 | 决策现场 |
| `项目总览/md/adr/` | 难以回头的决定，各一页；项目已有 ADR 目录则沿用 | 决策现场 |
| `项目总览/md/` 其余 | 架构、术语等跨专题资料 | 主控 |
| `项目总览/html/` | 阅读页：每轮一页决策简报，程序从卡生成；架构图按需由 Archify 生成，每张一个独立 HTML，同名 JSON 规格留在旁边作下次对比的前一版 | 建图 |
| `专题工作/某专题/决策卡/` | 该专题每个问题一张卡；写法和状态五值见共享规程 03“决策卡写法” | 决策现场 |
| `专题工作/某专题/` 其余 | 策划书、Spec、施工票、验收记录和证据，专题索引 | Spec 和票由主控写；票的记录和索引由执行者写 |
| 所属目录的 `历史/` | 被替代的 Spec、票等旧版本，保留批准依据和现行版本去向；决策卡和 ADR 不进历史，原位改状态 | 替换它的写手 |

MD 是事实源，HTML 是阅读副本。有效决定和已完成的票留在所属专题，完成不等于进历史。

## 决策卡写法

本节是各项目共用的写法：生成项目 AGENTS 时不抄进去，项目里写卡和地图 MD 直接按本节。

每张卡一个文件，`专题工作/<专题>/决策卡/NN-名称.md`。开头是固定标签，一行一项，冒号用中文全角；正文是固定标题的段落。程序按标签和标题读，缺标签报错；某项没有内容写“无”，不留空。

```text
# 决定：[结论句，作标题；未定时写“未定：问题一句”]

状态：[未定 / 已定 / 否决 / 暂缓 / 已被某卡取代]
定于：[日期；未定写“无”]
谁定的：[人；未定写“无”]
出处：[批准原话所在的文件与位置；未定写“无”]
依赖：[前置卡名称与相对链接，一行一个；无则“无”]
取代：[本卡取代的卡名称与链接；无则“无”。旧卡的状态行同时改为“已被某卡取代”并链到本卡]
影响哪些卡：[本卡改动会牵动的卡名称与链接；无则“无”]

## 问题
[一两句背景，用用户的语言]

## 比较过的选项
| 做法 | 好处 | 代价与风险 | 排除理由 |
|---|---|---|---|

## 选择与理由
[选了什么，为什么更好]

## 影响
[接受的代价；对成本、进度、使用、维护和其他决定的影响；改旧决定时写“原值 → 本次 → 新值”]

## 前提
| 前提 | 谁负责满足 | 何时核实 | 不满足怎么办 |
|---|---|---|---|

## 依据
[可点开的相对链接，一行一个：查证记录、ADR、原型、讨论记录]

## 后续
[谁＋做什么＋何时之前，一行一个；无则“无”]

## 暂缓原因
[状态为暂缓时必填：为什么不定、重新考虑的触发条件；其他状态写“无”]
```

标题写决定本身，不写问题；人读文字用名称，不用裸编号；编号只出现在文件名和链接里。研究卡（只查证不决定）用同一写法：状态写“未定”，查证完成写“已定”，被取代时同其他卡；“比较过的选项”写“无”；结论放“查证结论”段，代替“选择与理由”。

### 地图 MD 头字段

`项目总览/md/决策地图.md` 开头固定五个标签，之后才是每个问题一行的索引：

```text
轮次：[第 N 轮；日期]
本轮范围：[一句]
要用户决定：[没有写“无”；有的每项一行：问题一句；选项一行一个含“什么都不做”，各附代价；推荐及理由；何时之前；不定会挡住什么]
下一步：[谁＋做什么＋何时之前，一行一个]
上一轮简报：[相对链接；首轮写“无”]
```

有多项的标签（要用户决定、下一步）：标签行之后接着写，到下一个标签为止，中间可以空行；每项一行、不缩进，写不写列表符号都行；一项的子项（选项、推荐、何时之前、会挡住什么）缩进两格写在该项下面。

简报文件名写 `决策简报-第N轮-YYYYMMDD.html`，日期用那一轮的轮次日期；下一轮从“上一轮简报”链到的文件名取这个日期划本轮范围，读不出或不早于本轮日期时报错。

索引行写法不变：每个问题一行，问题、依赖、状态和一句摘要加链接，不复述卡的内容。
