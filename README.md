# 建筑师的 AI 开发手册

用建筑师熟悉的工作逻辑，串起从想法到可用工具的 AI 开发过程。

**这份手册后续会持续更新。** 我会结合实际使用经验，逐步补充案例、修订操作方法，并更新工具与协作流程。欢迎收藏在线阅读链接，之后可在同一地址查看新版。

**[点击在线阅读完整手册](https://zhoufff.github.io/architect-ai-handbook/)**

**[下载 HTML 离线版](https://raw.githubusercontent.com/zhoufff/architect-ai-handbook/main/index.html)**（打开链接后另存为 `.html`，用浏览器打开即可）

## 四个核心阶段

| 阶段 | 解决什么 | 主要成果 |
| --- | --- | --- |
| 场景研究 | 为什么做、给谁用、第一期解决什么 | 策划任务书 |
| 概念原型 | 任务怎样走、页面怎样看 | 可点击原型与设计基线 |
| 施工准备 | 规格、技术取舍与开发顺序 | 规格书与施工任务 |
| 开发交付 | 逐项实现、验证与人工验收 | 可用成果、证据与当前状态 |
