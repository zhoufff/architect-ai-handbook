# 决策简报 1.0

从项目的决策卡和地图 MD 生成每轮一页的精简简报（HTML）：首屏五栏是要你决定、本轮定了什么、改了哪些旧决定、带前提或未定、下一步，每行一个短语；点开看选项、理由、影响和依据。决定只住在卡和地图 MD 里，简报是生成的阅读副本；平时查决定靠问答，简报只作每轮一页的通知。

- Agent 怎么用：[SKILL.md](SKILL.md)。
- 卡和地图 MD 的写法：共享规程 [03 的“决策卡写法”](../../协作规则/03-项目规则模板.md#decision-card)。
- 样本：[examples/决策简报-示例.html](examples/决策简报-示例.html)，由虚构项目 `examples/示例项目/` 生成。

## 运行

Node 18 及以上，不装任何依赖：

```sh
node scripts/brief.mjs --source <项目根> --output <项目根>/项目总览/html/决策简报-第N轮-YYYYMMDD.html
```

- **读**：`项目总览/md/决策地图.md` 开头的五个标签，`专题工作/*/决策卡/NN-*.md` 的全部卡；另外核对页面里每个链接指向的文件是否存在。
- **写**：只写 `--output` 这一个文件，同名覆盖。输出目录要已存在，且和项目在同一个盘，因为页面里全是相对链接。
- **文件名**：日期写本轮“轮次”的日期。下一轮的地图 MD 在“上一轮简报”里链到这份文件，生成器从文件名取上一轮的日期，划定哪些卡算本轮。
- **多行的标签**：地图 MD 的“要用户决定”“下一步”，卡的“谁定的”“出处”“依赖”“取代”“影响哪些卡”，都可以接着写几行，写到下一个标签为止，中间可以空行。“要用户决定”“下一步”每条写一行、不缩进（写不写列表符号都行），这一条的细节缩进写在它下面；行首的 Tab 按四个空格算。
- **终端**：成功时打印输出路径、本轮计数、链接自检结果，以及“提示”行。读不出时按文件列出缺什么，退出码 1，不写页面。

## 首屏五栏怎么取

| 栏 | 取自 |
|---|---|
| 抬头 | 标题“第 N 轮决策简报”、一句计数、本轮范围；右上角图签是项目、日期、轮次、上一轮简报的链接 |
| ① 要你决定 | 地图 MD 的“要用户决定”：每条一行，缩进的细节点开才看到；写“无”就显示“无” |
| ② 本轮定了什么 | “定于”落在本轮范围里的已定卡和否决卡。本轮范围指上一轮简报文件名里的日期之后、到本轮轮次日期为止；首轮指轮次日期及以前 |
| ③ 改了哪些旧决定 | ②里已定卡的“影响”中，每条“原值 → 本次 → 新值”一行，显示为原值划掉 → 新值，详情里列出新卡取代的卡；只写了“取代”、没写这一行的，每张被取代的卡一行 |
| ④ 带前提或未定 | ②里“前提”不是“无”的已定卡；全部未定的决策卡；全部暂缓的卡。研究卡（写“查证结论”的卡）不上首屏，没被取代的在这一栏末尾列名 |
| ⑤ 下一步 | 地图 MD 的“下一步”，每条一行；提到“用户”的标“涉及你” |

每行显示卡的标题，去掉“决定：”“未定：”前缀；标题里有“：”时分两栏（话题｜结论）。标记有五种：否决、带前提、△ 改了旧决定、未定、暂缓。

点开一张卡，依次看到：状态与批准（状态、定于、谁定的、出处）、问题、比较过的选项、选择与理由（研究卡为查证结论）、影响、前提、依据、关系、后续、暂缓原因，最后是原文链接。写“无”的照样显示“无”。
- “关系”照卡上的原行显示，链接后面的说明也在。“影响哪些卡”先列卡上写的；别的卡的“依赖”写了本卡、本卡却没写的，补在后面并注明是反查来的。
- 链接指向本页有详情的卡，就在页内跳转；其余链接打开 MD 原文。

## 报错停止的情况

- **标题和标签**：标题行不是“# 决定：…”或“# 未定：…”；缺标签、标签没内容、标签用了半角冒号、标签写了两次。
- **段落**：缺段落、段落是空的（只有表头、没有数据行的表格也算空）、段落写了两次。
- **状态和日期**：状态不在五值内；已定、否决的卡“定于”写了“无”；“定于”既不是日期也不是“无”；暂缓的卡没写暂缓原因。
- **关系**：“依赖”“取代”“影响哪些卡”某一行没有链接；“取代”链到的不是本项目的卡。
- **取代两边对不上**：新卡写了取代，旧卡状态却不是“已被某卡取代”；旧卡状态行链到的卡没写取代它；或者两边都查不到是谁取代的。
- **影响**：带“→”的行拆不成三段。
- **地图 MD**：缺五个标签之一；轮次不是“第 N 轮；YYYY-MM-DD”；上一轮简报的文件名读不出日期，或日期不早于本轮。
- **链接和输出**：页面里的链接写成绝对路径，或指向的文件不存在；输出目录不存在；输出路径是个目录；输出和项目不在同一个盘。

“已被某卡取代”认两种写法：`已被某卡取代：[新卡](链接)`，或 `已被[新卡](链接)取代`。状态行没写链接时，由新卡的“取代”反查。研究卡的状态不做限制，被新研究卡取代时照样写“已被某卡取代”。

## 终端提示的情况

下面这些不挡生成，但简报不会显示，成功时在终端各提示一行：
- 卡开头有不属于任何标签的行；
- 卡里有附录 A 以外的段落（决策卡多写了“查证结论”也算）；
- 决策卡目录里有文件名不是“NN-名称.md”的 MD 文件，没有当作卡读；
- 已定、否决的卡“定于”晚于本轮轮次日期，本轮首屏不显示。

## 安装为技能

安装要用户当次同意。下面两种方式选一种维护：

- **目录链接**（本机做法）：Claude Code 建 `~/.claude/skills/decision-brief`，Codex 建 `~/.agents/skills/decision-brief`，都指向本目录。Windows 用 PowerShell 7，例如：

  ```powershell
  New-Item -ItemType Junction -Path "$HOME\.claude\skills\decision-brief" -Target "<仓库>\工具\决策简报"
  ```

  macOS：`ln -s "<仓库>/工具/决策简报" ~/.claude/skills/decision-brief`。
- **复制**：把 `SKILL.md`、`README.md` 和 `scripts/` 复制到上面的目录，`examples/`、`test/` 可一并复制。

Claude Code 只认 `~/.claude/skills` 和项目的 `.claude/skills`，不读 `~/.agents/skills`。装好后在对话里要“本轮决策简报”，或输入 `/decision-brief`；如果 `~/.claude/skills` 是这次安装才新建的，重启后再试。

在本目录运行 `node --test`。测试把 `examples/` 复制到系统临时目录再改，不写本目录；测试用到 `fs.cpSync` 等较新的接口，在 Node v24 上跑过。改了生成器或样本之后，重新生成入库的样本页，否则“样本生成幂等”那条测试会失败：

```sh
node scripts/brief.mjs --source examples/示例项目 --output examples/决策简报-示例.html
```

- `examples/示例项目/` 是虚构的“河畔书屋借阅小程序”第 2 轮：8 张卡，已定、未定、暂缓、否决、被取代、带前提、改旧决定各至少一例，另有一张研究卡。
- 第 1 轮简报在 `examples/示例项目/项目总览/html/`，是第 1 轮结束时生成的上一轮输出，供“上一轮简报”链接，不再重生成。

## 已知限制

- **首屏一屏**：样本在常见桌面尺寸下五栏都在一屏内，手机宽度变成单栏，顺序 ① 到 ⑤。一轮的决定太多时会超过一屏，说明这一轮该拆开。
- **本轮只靠日期划分**，没有快照：
  - 前几轮定的卡本轮只改了措辞、没改“定于”，不会出现在 ②。
  - “定于”和上一轮简报同一天的卡算上一轮；上一轮简报生成之后才记下的，要重出上一轮，或者按实际日期写。
  - “定于”晚于本轮轮次日期的卡本轮不显示，终端会提示。
  - 前几轮定的卡和研究卡都不上首屏，从关系和依据链过去。
- **上一轮日期只从文件名取**，文件名要守约定。
- **一张新卡取代几张旧卡、又只写了一条箭头行时**，③ 只按箭头行出一行，取代的卡都列在这一行的详情里，程序对不出箭头行说的是哪一张。
- **Markdown 只认卡里用到的写法**：段落、缩进列表、表格、三级以下标题、粗体、行内代码。代码块、图片、HTML 不支持。
- **箭头只认“→”**：半角的“->”不算改旧决定；普通叙述里用了“→”会被当成改旧决定的写法。
- **依据链接打开的是 MD 原文**，浏览器会按纯文本显示或提示下载；简报不嵌入原文。
- **首屏一行**：话题一栏放不下时截断，悬停看全名；结论照原文换行。
- **只测过 Node v24**。脚本只用了 Node 18 已有的接口，Node 18 没有实机跑过。
